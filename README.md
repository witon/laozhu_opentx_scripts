# EdgeTX/OpenTX 滑翔机比赛辅助脚本

专为 **F3K（手抛滑翔机）** 与 **F5J（电动滑翔机）** 训练和比赛设计的遥控器脚本：计时与记录、遥测显示、以及一组地面调机小工具。脚本运行在支持 Lua 遥测的 EdgeTX（或兼容）遥控器上。

---

## 脚本能做什么

### 3ktel（F3K）

- 按你选的 F3K 任务做轮次与窗口计时，显示当前状态与飞行时间  
- 可设**目标飞行时间**，到时语音提醒  
- 记录本轮多次飞行的成绩，可在页面上翻看列表  
- 用滑杆选择要语音播报的遥测项（如信号、时间、高度等，取决于你的模型与传感器），再用播报开关收听  

### 5jtel（F5J）

- **工作时间（WT）**与**加电时间（PT）**分别计时  
- 检测油门是否超过设定阈值，提示重复开动力等情况  
- 显示并记录起飞高度、飞行高度等信息  
- 同样可用滑杆选播报项 + 开关播报回传数据  

### adjust（调机工具）

进入后会出现一行行菜单（名称看起来像文件路径，忽略即可），从上到下依次是：

1. **全局变量** — 改遥控器全局变量  
2. **输出通道** — 调舵机行程、中位、曲线等  
3. **下沉率** — 测下沉率、记历史、对比  
4. **升阻比（LD）** — 测滑翔性能相关数据  
5. **弹射/发射** — 记录与分析弹射高度等  

用摇杆 **上/下** 选中一项，**确定** 进入；子工具里按屏幕提示操作；**EXIT** 返回上一级菜单。

## 安装到 SD 卡

### 自动安装（推荐）

**Windows：** 在安装包目录运行 **`install.bat`**，按提示输入 SD 卡盘符（如 `F:`）。

![](https://gitee.com/dacaodi/laozhu_opentx_scripts/raw/master/document/screenshot_install_cmd.png)

![](https://gitee.com/dacaodi/laozhu_opentx_scripts/raw/master/document/screenshot_install_click.png)

![](https://gitee.com/dacaodi/laozhu_opentx_scripts/raw/master/document/screenshot_install_copy.png)

**macOS：** 在解压后的仓库根目录执行：

```bash
./install_mac.sh "/Volumes/你的SD卡卷名"
```

按提示把 **`SCRIPTS`**、**`LAOZHU`**（以及可选的 **`WIDGETS`**）同步到 SD 卡。

### 手动安装

把仓库里的 **`SCRIPTS`** 整个拷到 SD 卡 **`SCRIPTS`**；把 **`LAOZHU`** 拷到 SD 卡根目录，与 **`SCRIPTS`** 并排。若用彩屏 Widget，再把 **`WIDGETS`** 拷到卡根目录。  
卡上没有 **`SCRIPTS/data`** 文件夹时，可自己建一个空目录，飞行与调机会往里面写记录。

### 在遥控器里挂上脚本

1. 打开 **DISPLAY（遥测屏）** 或对应机型上的 **Telemetry screen** 设置  
2. 选本仓库提供的脚本，例如 **3ktel**、**5jtel**、**adjust**；若需配置按键映射，可另挂遥测脚本 **key**（见下文）  

![](https://gitee.com/dacaodi/laozhu_opentx_scripts/raw/master/document/screenshot_xlites_3k_install.png)

### 第一次打开

第一次进入脚本时，遥控器会自动编译 Lua，请稍等直到结束。

![](https://gitee.com/dacaodi/laozhu_opentx_scripts/raw/master/document/screenshot_xlites_compiling.png)

![](https://gitee.com/dacaodi/laozhu_opentx_scripts/raw/master/document/screenshot_xlites_finish_compile.png)

完成后用 **EXIT** 退出编译界面，再正常进入功能。

## 使用说明：3ktel（F3K）

### 飞行模式怎么起名（重要）

脚本用**飞行模式的名字**判断阶段。请在你的模型里使用小写英文名：

- **`preset`** — 例如抬头/预备姿态  
- **`zoom`** — 例如爬升  

只有按规则从 **preset → zoom → 再离开 zoom 进入飞行 → … → 着陆**，才会记成一次有效飞行；起飞前请在地面确认这两个模式名称无误。

### 设置里有什么

- **长按 MDL** 进入**任务 / 轮次**相关设置：比赛任务类型、目标时间的调节步长、准备时间、测试时间、禁飞时间等（具体选项以你屏幕上为准）  
- 在同一套设置流程里还可以进到**开关与播报**：轮次开始、重置计时、语音播报用的滑杆与开关等  

### 平时怎么用

1. 上场前在设置里确认任务类型、开关、播报都已配对好  
2. **飞行主页**上看当前任务、状态、飞行时间、目标时间等  
3. 需要改**目标飞行时间**时：在飞行主页按 **确定**，用 **上/下** 按步长调节（步长在设置里定义），再按 **确定** 保存  
4. 准备这一轮：按你在设置里指定的 **重置开关**，把计时复位  
5. 正常飞行：用手抛与模式切换完成起飞与着陆，脚本会计时并记录  
6. 想听语音：先把滑杆拨到要听的参数，再打开播报开关  
7. 用 **翻页键** 在「主飞行页」和「本轮成绩列表」之间切换（哪两颗键取决于你的遥控器型号与脚本按键映射）

## 使用说明：5jtel（F5J）

1. 进 **设置页**：配好重置开关、飞行开关、油门通道、油门阈值、播报滑杆与开关  
2. 飞行时：**工作时间**按规则倒计时；油门超过阈值计入 **加电时间**；显示起飞高度、当前高度等  
3. 注意屏幕上的重复加动力等提示；需要语音时同样：滑杆选内容 + 开播报  

---

## 使用说明：adjust（调机）

1. 运行 **adjust**，用 **上/下** 选工具，**确定** 进入  
2. 在工具内按提示测量、调节、保存  
3. **EXIT** 回到工具列表；再 **EXIT** 退出脚本

## 使用说明：按键映射（key / LzKey）

仓库中 **`LAOZHU/key`** 为 **3ktel**、**5jtel**、**adjust** 等界面提供统一的「硬件按键 → 逻辑方向 / 返回 / 长按」映射。遥控器型号或固件与内置默认不一致、方向键或翻页异常时，可用本工具生成映射文件。

### 如何打开

- **黑白屏遥测**：在遥测屏设置里选择脚本 **key**（与 **3ktel** 等同级）。
- **彩屏 Widget**：在布局里添加 **LzKey**（见下表）。建议使用 **App 模式**；需先 **长按 ENTER**（或长按触摸）交权后，按键事件才会送入脚本。

### 调试页做什么

屏幕会显示固件信息，以及每次按键的 **原始 event**、**映射后 event** 与时间。点右上角 **setkey**（触摸），或按当前映射下的 **确定**，进入映射配置向导。在调试页按 **EXIT** 可退出整个 **key** 遥测脚本。

### 映射配置向导

1. 前半段依次捕获 **上、下、左、右、返回**：每一步约有 **5 秒**窗口，请按下对应物理键；窗口内**最后一次**按键生效；若超时未按，则该步留空并写入配置。
2. 完成后进入主界面，可进入 **扩展键**，继续配置长按方向等键位。
3. 向导内按 **EXIT**：从扩展子界面回到主界面，从主界面退出则回到调试页（屏幕提示可能为 leave / back，含义为返回上一级或结束向导）。

### 配置文件与生效方式

- 映射写入 SD 卡 **`SCRIPTS/keymap.cfg`**。
- 若该文件**存在且可读**，主功能脚本将**只**使用该文件中的映射，不再使用按型号内置的默认表。
- 修改映射后，需**重新进入** **3ktel** / **5jtel** / **adjust** 等脚本，才会重新加载新表。请与其它 **`*.cfg`** 一并备份（含 **keymap.cfg**）。

### 关键键映射错误、无法再次进入向导时

若不小心把「**返回**」「**确定**」等关键键映射到错误的物理键上，可能无法再触发 **setkey** 或按提示进入映射向导。可在遥控器 **设置** 里打开 **SD 卡文件浏览**（或本机等效的文件管理入口），删除 **`SCRIPTS/keymap.cfg`**，**重启遥控器**；启动后映射会回到内置默认，再运行 **key** / **LzKey** 重新配置即可。

## 彩屏遥控器（Widget）

若 SD 卡根目录已放入 **`WIDGETS`**，可在 EdgeTX 彩屏主机的 **App / Widget** 布局里添加：

| Widget | 对应功能 |
|--------|----------|
| **Lz3k** | 与遥测 **3ktel** 同一套 F3K 功能 |
| **Lz5j** | 与遥测 **5jtel** 同一套 F5J 功能 |
| **LzAdjust** | 与遥测 **adjust** 同一套调机菜单 |
| **LzKey** | 与遥测 **key** 同一套按键调试与映射向导（详见上一节） |

大屏上布局可能与黑白小屏不同，若显示不全，尽量给 Widget 较大区域或使用全屏类布局。

## 兼容性与注意

- 仓库曾在 **RM Zorro + EdgeTX v2.9.4** 上验证；其它支持 Lua 遥测的遥控器亦可尝试，以本机实测为准  
- 首次使用务必等编译结束  
- 比赛前在地面完整走一遍：**模式名、开关、计时与记录**是否符合预期  
- 定期备份 SD 卡上的 **`SCRIPTS/data`** 里的记录和 **`SCRIPTS`** 下的 **`*.cfg`** 配置（含按键映射 **`keymap.cfg`**）  
- 保持遥控器电量充足，并遵守赛事规则
